# Budget and Cost Management

## Project Budget

The current project documentation estimates the overall cost of developing and rolling out the FreshChoice SafeStore system at AUD $5,000-$7,000.

| Cost Area | Status |
|---|---|
| Overall project development and rollout | Estimated AUD $5,000-$7,000 |
| Python development environment | Used in project; paid cost not separately recorded |
| GitHub | Used for source control and collaboration; paid cost not separately recorded |
| Jira | Used for project and sprint management; paid cost not separately recorded |
| SMS/notification services | To be confirmed during Iteration 3 |
| Actual project expenditure | Not separately recorded in current project evidence |

## Cost Tracking Approach

The project distinguishes between the estimated overall project budget and verified actual expenditure. Where an actual paid amount is not available in the current project records, it is not presented as a confirmed cost.

The budget information will be reviewed alongside the Iteration 3 implementation and notification requirements.

## Evidence Source

The AUD $5,000-$7,000 overall estimate is recorded in the project retrospective documentation.
